# 美颜自拍亭 · GitHub 项目介绍

美颜自拍亭（BeautyPhotoBooth）是一款开源免费的 Windows 中文自拍亭软件，把模板选择、倒计时连拍、本地一键美颜、自动套版、原片/美颜对比和 DNP DS620 打印串成完整流程。支持佳能原生联机拍摄，以及 Windows USB 视频流兼容拍摄；软件启动后自动识别设备名称、型号和驱动状态，并可通过 Windows Update 匹配缺失的相机驱动。模板可批量添加，自动识别透明框与独立浅色空白框，再拖动调整照片框位置、大小及框内照片取景。Logo 和标题可替换，原片单独保存，照片在本机处理。

v1.1.1 改进大屏触摸使用体验：欢迎封面与成片预览随屏幕放大，模板按可用空间网格排列并分页，切换全屏时自动适配。

## 使用范围说明

- 佳能原生联机已验证 EOS R6 Mark II；其他机型需相应 EDSDK 支持并自行验证。
- 索尼、松下等支持 Windows 视频输出的机型，可用 USB视频或 HDMI 采集卡输入；画质由视频输出决定，不等同于原生高像素照片。
- 本版本尚未接入索尼、松下原生遥控 SDK。SDK 获取可能需要申请、相机序列号和厂商许可，不能靠普通驱动自动解决所有型号的联机控制。
