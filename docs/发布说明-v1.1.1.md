# 美颜自拍亭 v1.1.1 - 全屏显示优化

本软件开源且免费，请注意不要受骗。

本项目由 Codex 制作，作者不懂代码，欢迎大佬交流。作者：爱打游戏的Arweil，联系方式 QQ:759377831。

本次改进欢迎页、模板选择和成片预览的大屏体验：欢迎封面与成片会按窗口等比例放大，完整保留内容；模板按可用空间排成更大的网格，排满后翻页；切换 F11 全屏或调整窗口时自动适配，减少大块空白，保留可见操作按钮。美颜参数、照片处理与 DS620 打印逻辑沿用上一版。

## 下载与安装

- Windows 10/11 x64：下载 BeautyPhotoBooth-1.1.1-Setup.exe，完成安装后使用桌面“美颜自拍亭”快捷方式。
- 已有用户：先退出程序，备份 config.json、assets、data，再安装到原目录。安装程序保留已有设置、导入素材与照片。
- 开发者：下载 BeautyPhotoBooth-1.1.1-Source.zip，解压后把 BeautyPhotoBooth 文件夹内的内容放到仓库根目录。
- 操作指南与完整更新记录见附件及源码中的 docs/操作指南.pdf、CHANGELOG.md。
- SHA256SUMS.txt 可用于核对附件完整性。

## 适用范围

佳能原生联机需本机合法安装的 64 位 EDSDK，已验证 EOS R6 Mark II；索尼、松下目前使用设备提供的 Windows 视频流或 HDMI 采集卡，尚未接入原生遥控 SDK。打印代码目前适配 DNP DS620 的 6×4 英寸相纸。

缺失驱动修复依赖 Windows Update 的适用驱动、网络与权限，尚未实机验证下载安装流程。
