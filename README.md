# 美颜自拍亭 BeautyPhotoBooth

开源免费的 Windows 中文自拍亭，把选模板、拍照、本地一键美颜、套版、对比和 DS620 打印串成一个流程。

**本项目由 Codex 制作，作者不懂代码，欢迎大佬交流。作者：爱打游戏的Arweil，联系方式 QQ:759377831。**

## 主要功能

- 顾客按一次，每张倒计时 5 秒，按模板张数自动连拍；工作人员可点立即拍摄或按空格。
- 本机一键美颜：提亮、阴影提升、磨皮、大眼、瘦脸、减弱油光、淡纹和轻微身体调整；保留原片，一键切换对比。
- 模板批量导入，识别透明照片框与独立浅色空白框；框内拖动移动、右下角缩放、精确坐标编辑、照片内容平移与放大，支持撤销。同一照片编号可以重复用于左右条带。
- 启动时自动检测相机型号、驱动与可用视频接口；自动寻找本机合法安装的佳能 EDSDK。缺少相机驱动时尝试通过 Windows Update 匹配，不更新健康设备、固件或其他硬件。
- Logo 和预览标题可编辑，封面可替换，删除和替换的素材可恢复；原始导入文件不覆盖。
- 成片确认后提交 DS620 打印，记录任务号并防止状态不明时盲目重复提交；提交成功后回到欢迎页。
- 安装包自带 Python 运行环境，创建桌面快捷方式，升级保留配置，卸载保留照片与素材。

默认标题：**拍照免费，删一张50（本标题可编辑）**。默认透明 Logo 是作者提供的黑色图形加“logo可替换”。

## 相机兼容范围（请先看这里）

| 方式 | 可做什么 | 条件与状态 |
| --- | --- | --- |
| 佳能原生联机 | 遥控快门、照片下载、取景、相机支持的点按对焦 | 需合法安装 64 位 EDSDK；已实机验证 EOS R6 Mark II，其他机型需 SDK 支持并验证 |
| USB视频兼容 | 取景、倒计时 / 人工取帧、美颜套版与打印 | 相机须支持 Windows 视频输出，或使用 HDMI 采集卡；按实际视频分辨率保存，不触发相机原生高像素照片快门，也不支持镜头点按对焦 |
| 索尼 / 松下原生遥控 SDK | 本版本尚未实现 | 官方 SDK 可能需要申请、序列号和许可；装上驱动并不等于已支持原生联机 |

USB视频方式适用于能提供视频流的 Sony、Panasonic 等相机、采集卡和摄像头；目前未连接索尼或松下实机验机，不保证所有型号。自动方式不会擅自选择笔记本内置摄像头；多个外接候选设备时要求工作人员选择。

[Sony Camera Remote SDK 官方资料](https://support.d-imaging.sony.co.jp/app/sdk/en/index.html)；[Panasonic LUMIX SDK 官方资料](https://av.jpn.support.panasonic.com/support/global/cs/soft/tool/sdk.html)。

已验证打印环境：Windows x64 + DNP DS620 + 6×4 英寸（约 10×15 cm）相纸。当前打印代码限定 DS620；其他打印机需适配。相机取景与成片分辨率不是一回事；已测 R6 Mark II 取景约 960×640、相机照片 6000×4000，本地处理最长边缩至 3000。

## 安装与首次设置

1. 安装 DS620 官方驱动，连接相机和打印机 USB，唤醒相机。相机切到遥控 / PC连接方式；USB视频模式则按相机说明启用视频输出。
2. 运行 `BeautyPhotoBooth-1.1.0-Setup.exe`，看到免费防骗提醒与作者信息后完成安装。桌面快捷方式为“美颜自拍亭”。默认目录 `%LOCALAPPDATA%\Programs\OpenPhotoBooth`，沿用原版本目录便于升级。
3. 首次打开自动检测设备并尝试连接。F10 → “相机自动检测 / 连接方式 / 驱动”可查看具体型号、驱动状态，选择佳能原生或明确的 USB视频设备。
4. 佳能未找到接口时，F10 选择本机已合法安装的 64 位 EDSDK.dll；其配套 DLL 保留在原目录。索尼 / 松下原生 SDK 未接入，不能选择厂商 DLL 冒充佳能 SDK。
5. 驱动缺失时只匹配 Windows Update 中适用相机的硬件 ID。需要网络及相应权限；可点“管理员修复缺失驱动”，由工作人员确认 Windows 提示。无匹配包时使用官方入口；软件不自动注册账号、申请 SDK、升级固件或重启电脑。
6. F10 选择 DS620 队列；驱动中设置 6×4 英寸相纸并做一张打印测试。双三格默认整张出纸，裁切取决于驱动设置。

模拟演练：开始菜单 → “模拟演练（不打印）”，或 `PhotoBooth.exe --demo`。模拟图片带明确标记，不提交实际打印任务。

## 模板简单编辑

F10 → Logo / 标题 / 封面 / 模板管理 → 拍照模板 → 批量添加。Ctrl / Shift 可一次选多张。

自动识别后显示需要拍几张。透明框优先；没有透明框时尝试识别被边界隔开的浅色空白框。整页白纸、复杂图案或不确定的图片需要手动画框，不会凭空猜测。

选中模板 → 编辑照片框 / 名称：

- 空白处拖动新增；框内拖动移动；右下角小方块拖动缩放。也可点“精确调整位置 / 大小”。
- 切到“照片内容”模式，在框内拖动调整照片取景；用照片放大滑块裁去多余背景，“照片位置复位”可还原。
- 设定每个框使用第几张照片，编号须从 1 连续排列。同一编号会重复使用同一张；双三格可点“两列同组照片”。最多 16 框、12 张独立照片。
- “撤销”恢复最近框编辑。改变窗口位置时，原窗口会按周围底色补齐；复杂装饰请检查预览，精细改图可先用图片编辑软件处理。
- 先“保存照片框”，再“保存并应用”。主窗口取消则不应用草稿；删除 / 替换的旧版本可恢复。

## 拍照与快捷键

欢迎页 → 模板 → 自动倒计时 / 立即拍摄 → 等待美颜与套版 → 开关对比 → 打印 / 重拍。打印“已提交”表示 Windows 接收任务，不等同于确认实际出纸。

| 快捷键 | 功能 |
| --- | --- |
| F10 | 工作人员设置 |
| F11 | 切换全屏 |
| 空格 | 拍摄页立即拍摄 |
| Esc | 退出全屏；窗口模式下取消倒计时 |

原生佳能的白框是检测人脸，黄色为对焦中，绿色为相机确认合焦，橙色为未确认。USB视频模式不把取景点选伪装成相机已合焦，请在相机上调焦。

原片与成片：`data/sessions/`；模拟照片：`data/demo/`；日志：`data/booth.log`；配置：`config.json`；导入素材：`assets/library/`。退出后备份 config.json、assets、data 可迁移。升级保留已有标题和 Logo，默认标题只作用于新配置；卸载保留素材与照片，没有自动清理照片功能。

教程见 [操作指南](docs/操作指南.pdf)。当前使用本机算法，未连接像素蛋糕“我的 / 客户”预设。

## 开发、构建与签名

Windows x64、Python 3.12 x64：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r source\requirements.txt
.\.venv\Scripts\python.exe source\app.py --demo
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\Build.ps1 -InnoCompiler 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

完整运行目录在 build-work/dist/PhotoBooth，安装包在 releases。使用干净公开源码构建，不要混入现场照片或 assets/library。示例模板可用 tools/create_demo_assets.py 重建，脚本保留作者默认 Logo。

当前没有代码签名证书，**EXE 和安装包未签署 Authenticode 数字签名**；作者名称属于署名。工程提供 tools/Sign.ps1 和 Build.ps1 的证书参数，取得正式证书后可签名并验证；详见 [签名与作者](docs/签名与作者.md)。不创建自签名证书或修改系统信任设置。
